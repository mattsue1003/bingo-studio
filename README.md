# 童趣賓果工作室

給社區、特教、早療老師與家長使用的賓果卡生成器，適合帶團體活動。整個工具是一個網頁檔，用瀏覽器打開就能使用，不需要安裝。

## 功能

- **活動模板**：10 個現成活動，例如特教班小團體、全班活動、社區親子、長者跨齡共融。每個模板都排好局數、時間、人力分工和主持流程。
- **15 個主題與教案**：動物、蔬果、交通、情緒、身體、生活自理、社區、職業、顏色形狀、數字、注音、天氣、動作、安全、節慶。
- **14 種玩法**：一條線、雙線、四角、X、十字、外框、全滿、聽音找圖、看圖說說看、猜謎、動作、說一句話、尋寶、合作大賓果。
- **個別化名單**：每人一張卡，可以替每個人設定格子大小（3×3 到 5×5）、圖或字、大字。
- **叫號台**：國語朗讀、自動抽卡、投影全螢幕、對獎、自動偵測賓果、抽一位上台。
- **自訂內容**：可以輸入文字、上傳照片，也能用分享代碼和其他老師交換主題。
- **下載與列印**：提供 PDF、可編輯的 PPT（文字和圖片都能改），以及直接列印。

## 使用方式

- 線上使用：開啟 GitHub Pages 網址。
- 離線使用：下載整個儲存庫，打開 `index.html`。`img` 資料夾要和 `index.html` 放在同一層。

## 檔案說明

| 路徑 | 內容 |
|---|---|
| `index.html` | 賓果生成器本體 |
| `img/` | 326 張繪本風格圖卡，用 ChatGPT 生成 |
| `tools/` | 圖卡的提示詞，以及九宮格裁切腳本 |
